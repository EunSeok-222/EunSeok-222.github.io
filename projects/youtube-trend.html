유튜브 트렌딩 예측

한국 유튜브 트렌딩 영상 데이터에서 영상 메타데이터만으로 조회수 구간(상·중·하)을 예측하는 머신러닝 프로젝트.

개인 프로젝트 Kaggle 데이터 · 약 19,000개 영상
라이브 데모 ↗ GitHub ↗ Deck ↗

01

무엇을 풀려고 했나

Streamlit 기반 웹앱 — 영상 정보 입력 후 조회수 구간을 실시간 예측

유튜브 알고리즘에서 트렌딩 진입은 창작자에게 핵심 지표지만, 어떤 요소가 실제로 조회수를 결정하는지는 불투명합니다. 이 프로젝트는 "영상을 올리기 전에 알 수 있는 정보(메타데이터)만으로 조회수 구간을 어느 정도 예측할 수 있을까"를 데이터로 검증하는 게 목표였습니다.

Kaggle 글로벌 유튜브 트렌딩 데이터(113개국)에서 한국(KR) 데이터만 필터링해 약 19,000개 영상을 대상으로, 전처리·EDA·모델 비교·Streamlit 배포까지 전 과정을 혼자 진행했습니다.

02

구현 포인트

  • 피처 엔지니어링 — 좋아요/댓글 비율, 트렌딩까지 소요 일수, 채널 평균 조회수(로그 변환) 등 11개 피처 설계
  • 모델 비교 — 로지스틱 회귀·결정 트리·랜덤 포레스트·GradientBoosting을 비교해 최종 모델 선정
  • 실시간 예측 웹앱 — Streamlit으로 영상 정보 입력 시 조회수 구간을 즉시 예측

05

막힌 지점과 해결

01모델을 4개나 비교했는데 다 Accuracy 0.63 언저리에서 멈춤
증상

로지스틱 회귀(0.557)부터 랜덤 포레스트(0.624), GradientBoosting(0.611)까지 9개 기본 피처로 여러 모델을 비교했지만, 랜덤 포레스트를 하이퍼파라미터 튜닝(GridSearchCV)까지 해도 Accuracy가 0.636을 넘지 못했습니다.

원인

처음엔 모델 선택이나 튜닝이 부족한 줄 알고 튜닝에 시간을 더 썼는데, 어떤 모델을 써도 비슷한 수준에서 멈추는 걸 보고 모델의 문제가 아니라 피처가 부족한 것이라는 쪽으로 가설을 바꿨습니다. 제목 길이·태그 개수·업로드 시간대 같은 영상 자체의 메타데이터만으로는, "이 채널이 원래 얼마나 인기 있는가"라는 정보가 빠져있었습니다.

해결

채널 평균 조회수(로그 변환, log_channel_avg)와 트렌딩 기간 중 최고 순위(best_rank) 2개 피처를 추가해 9개 → 11개로 확장했습니다. 그 결과 GradientBoosting 기준 Accuracy/F1이 0.803까지 뛰었습니다 — 베이스라인 대비 +24.6%p.

배운 점

여러 모델을 바꿔봐도 성능이 비슷한 지점에서 멈춘다면, 그건 모델을 더 튜닝할 게 아니라 데이터(피처)가 문제를 풀기에 충분한 정보를 담고 있는지를 먼저 의심해야 한다는 신호였습니다.

06

배운 점과 한계

가장 크게 남은 것 — 모델 성능이 정체될 때 모델을 바꾸는 것보다 피처를 다시 살펴보는 게 훨씬 효과적일 수 있다는 걸 직접 겪었습니다.

남은 한계 — 조회수는 알고리즘·이슈·트렌드 등 메타데이터 밖 외부 요인 영향이 커서, 학술 연구에서도 메타데이터 기반 예측 정확도는 60~70%가 현실적 한계로 보고됩니다. 이 모델은 채널 피처를 더해 그 이상(0.803)을 냈지만, 쇼츠·최신 알고리즘 변화 등은 학습 데이터에 반영되지 않은 상태입니다.

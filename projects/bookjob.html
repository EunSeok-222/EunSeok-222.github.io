bookjob

출판인을 위한 구인·구직 플랫폼. 공고 탐색·지원부터 마이페이지, 커뮤니티, PWA 설치까지 지원합니다.

라이브 서비스 ↗ GitHub ↗

개요

라이브 서비스(www.bookjob.co.kr) 메인 화면 — 브랜드 컬러인 핑크(#EC4899) 기반

출판업계 종사자와 채용 담당자를 연결하는 구인·구직 서비스입니다. 실제 도메인(bookjob.co.kr)으로 운영 중이며, 배포·성능까지 GitHub Actions + Lighthouse CI로 관리합니다.

도메인 기반 폴더 구조(`main` · `job` · `Find` · `community` · `my` 등)로 화면·API·상태를 함께 관리하며, 팀원 2명이 도메인을 나눠 담당했습니다.

담당 역할

  • 메인 페이지 — 배너·팝업 등 프로모션 영역 구성, 설문조사 등 이벤트성 배너 노출 로직
  • PWA — 홈 화면 설치, 매니페스트·아이콘 세트 구성(vite-plugin-pwa + Workbox)
  • 마이페이지 — 지원 내역·스크랩 등 개인 활동 관리 화면
  • 관리자 페이지 — 공고·콘텐츠 관리 화면
  • 로그인/인증 — `ProtectedRoute` 기반 인증 라우트 가드로 비로그인 접근 제어

핵심 기능

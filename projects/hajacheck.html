사진을 올리면 하자를 찾고, 등급을 매기고, 보고서 초안까지 쓰는 AI 기반 시설물 외관 하자 점검 플랫폼.

2026.07 – 08 (4주) 8인 팀 · 메뉴 담당제 담당: 고객지원·실시간 상담
라이브 데모 ↗ GitHub ↗ Report ↗

개요

라이브 사이트 랜딩 화면 — "쿨-모노톤 미니멀" 디자인, 장식색 없이 흑백 위주

건물 외벽·교량 등 시설물 사진을 업로드하면 균열용 U-Net과 면적형 손상(박리박락·철근노출)용 YOLOv8이 하자를 탐지하고, 규칙 기반으로 A~E 등급을 매깁니다. 검수를 거친 결과는 LangChain 기반 LLM이 점검 보고서 초안과 법규 질의응답으로 이어집니다.

AI 심화 과정 8인 팀이 "메뉴 담당제"로 진행해, 팀원 각자가 화면·API·AI 연동을 전 계층에 걸쳐 직접 구현했습니다.

로그인 후 대시보드 — 하자 현황·등급 분포 요약

담당 역할

  • 고객지원 개발 · 실시간 상담 오너 — 상담 티켓 생성·배정·상태 전이, 상담원 콘솔과 사용자 채팅 UI를 분리 설계하고 전체 대화 흐름을 구현
  • RAG 챗봇 파이프라인 — 벡터+BM25 하이브리드 검색(RRF) 기반 법규 질의응답 챗봇을 상담 화면에 연동, 출처 인용 답변 UI 구성
  • STOMP 서버·인증·대기열 — WebSocket(STOMP) 기반 실시간 상담 서버 구축, 세션 인증 처리, 상담원 미배정 시 대기열 로직 구현
  • 협업 방식 — 8인 팀이 "메뉴 담당제"로 진행해 화면·API·AI 연동을 계층 구분 없이 직접 구현하는 구조에 맞춰 상담 도메인 전체를 엔드투엔드로 책임
